# 右键菜单

0.1.10 起，右键目录标题、会话行或文件结果即可打开对应菜单。鼠标悬停时也会出现“更多”按钮；触屏始终显示该入口。菜单只作用于所点对象，右键会话不会切换当前打开的会话。

| 对象 | 操作 | 行为 |
| --- | --- | --- |
| 目录 | 设置别名 | 复用当前用户的目录别名编辑；清空恢复文件夹名。 |
| 目录 | 复制完整路径、打开文件夹 | 使用真实本机路径，别名不影响操作。远端或已不可用目录没有本机路径时禁用。 |
| 会话 | 重命名 | 1–160 个字符；按当前用户保存，只改变显示名称，不修改任务描述、执行配置或其他设备资料。搜索也支持新名称。 |
| 会话 | 置顶、取消置顶 | 置顶会话排在所属目录最前；多个置顶项沿用最近更新顺序。取消后恢复原排序。 |
| 会话 | 移入回收站 | 使用现有确认、身份与运行中保护。恢复保留名称及置顶，永久删除清理这些偏好。 |
| 文件 | 打开 | 用 Windows 默认应用打开经授权且校验过的本机文件。 |
| 文件 | 打开所在目录 | 在资源管理器中定位文件。 |
| 文件 | 另存为 | 使用现有保存对话框与导出规则，取消不创建文件；浏览器使用下载。 |
| 文件 | 复制路径 | 复制已校验的本机文件路径。原成果不可用时使用完整的接收副本。 |

文件未完整接收时，菜单中的操作禁用。路径校验、默认应用、文件占用或剪贴板操作失败会显示错误，允许重试；不默默打开其他文件。既有文件名称左键仍可定位文件夹。

焦点位于对象或按钮时，Shift+F10 / Menu 键打开菜单。方向键、Home/End 移动焦点，Enter/Space 执行，Esc 关闭并还原焦点，Tab 关闭并继续正常导航。点击外部、滚动来源区域或改变窗口尺寸会关闭菜单。使用独立浮层避开侧栏裁切，并限制在视口内。

实现使用 `conversation_preferences` 表按 `(user_id, conversation_key)` 保存名称与置顶；写入检查登录用户当前可见会话及请求来源，不能通过提交用户 ID 修改别人的显示偏好。按字段更新避免重命名覆盖置顶状态，永久删除在现有 SQL 事务中删除所有相关用户偏好。回收站仍按三个日历月保留。

原生 `open_task_file` 与 `open_project_directory` 分开限定文件/目录类型，沿用主窗口和精确自有回环来源认证；拒绝相对路径、URL、设备/网络路径、数据流及重解析点。Windows 打开使用固定 `open` 动词，无参数或 shell 字符串拼接。实现依据：[Windows 文件关联接口](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shellexecutew)、[WAI 菜单键盘模式](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/)。

验证见 [VERIFICATION](VERIFICATION.md)；真实模型和用户安装版测试仍由用户安排。
