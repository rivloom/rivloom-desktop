# 连续会话、草稿与附件

更新：2026-09-19，本地源码未发布，正式版仍为 0.1.18。

已完成的早期普通本机 Task 也可在原会话继续输入，由接受人发送新消息；保留会话与消息历史，无须重新新建。空闲、已停止、失败、待验收和已完成状态可继续，正在执行或等待审批/回答时沿用原有处理入口。协作子任务与远端任务仍受各自协议约束。

已有会话输入区增加模型选择，随该会话草稿保存，不污染新会话的默认选项。工作流中的模型选择属于该条排队消息，当前轮保持不变，到下一轮准入时才应用；旧消息未指定模型时沿用前一轮。明确失效的模型保留原标识并提示重新选择，不自动替换。

自动调度未指定本机模型时，仍可按原规则选择其他合格 Node；本机默认模型不可用不代表所有远端都不可用。明确锁定本机且缺少模型时须先配置或选择。普通 Task 续聊后，状态提示以当前实际执行为准，不再被上一轮已结束的队列回执覆盖。

普通本机 Task 续聊使用持久请求标识，收到响应前重复发送相同消息不重复调用引擎。相同标识更换正文或模型会拒绝；提交中断且结果不确定时保留现场，不自动再次提交。换账号时先确认旧执行结束，再在所选账号创建引擎会话，保留旧可见消息并传递其完整背景；超过 128 KiB 明确拒绝换账号。

## 连续会话

新建及已有的工作流会话可以在完成后继续输入要求；执行中发送的消息先排队，当前轮成功结束且所有执行已经结束后自动按发送顺序开始下一轮。模型的问题在问题卡片里直接回答，回答属于当前轮，不进入队列。停止或失败会暂停消息队列，核对结果后可继续队列；未执行消息可取消。最多同时排队 50 条，每条最多 12,000 字符和 5 个附件。新会话统一使用工作流，旧 Brain 记录沿用原有继续规则。

会话 ID、名称、目录、设备选择和用户偏好保持稳定，完整要求、完成条件、问题回答、结果摘要及文件清单按轮次保留。下一轮重新规划，并通过完整 JSON 会话记录和已有成果继续；同名文件使用最近成果或本轮新附件。跨设备仍遵守目标设备权限与执行准入。引擎会为新的规划/步骤创建会话，并非复用一个无限增长的引擎 session。

材料沿用每个步骤最多 10 个、合计 1000 MiB 的限制，会话记录文件计入材料数；超限会明确暂停而非静默丢弃文件。含未执行消息的会话须先取消队列后才能移入回收站。自动接续消息阻止更新交接；显式暂停的终止轮次队列允许更新，重启后保留。

## 阅读与草稿

应用回答和结果支持标题、列表、表格、引用、行内代码、带语法高亮的代码块和独立代码复制；整条消息复制仍保留 Markdown 原文。HTML 不执行，Markdown 远程图片只显示说明，HTTP/HTTPS 链接在独立目标打开。

每个会话和新会话分别保存未发送文字、设备路由、提交请求标识与已上传附件；目录、模型、审批选项和完成条件也会恢复。草稿按当前设备与用户隔离，同时保存在浏览器和本机服务，服务重启或端口变化不丢失。只有确认发送成功才清空相应草稿；重复请求复用原标识。未上传完的文件不能从文件名还原，恢复后明确提示移除并重新选择。永久删除会清理对应草稿，过期客户端不能恢复已删除的内容。

## 附件

输入框支持 Ctrl+V 粘贴截图，附件文件可以拖入或通过选择器上传；完成上传后可预览。图片支持 PNG/JPEG/GIF/WebP，文本和代码最多预览前 256 KiB，音视频使用浏览器内置播放器与分段读取。HTML/SVG 等作为纯文本显示；其他格式保留下载后打开的提示。图片预览上限 20 MiB，具体音视频编码的播放能力取决于 WebView。所有预览继续检查上传者或实际任务成员权限，项目原始文件不受清理影响。
