# 简洁会话输入区

## 2026-09-19 当前本地源码，未发布

模型选择处新增状态提示和接入入口。本机没有可选模型时，可进入现有“设备与模型”添加账号或检查配置；工作区成员会看到联系创建者的说明。引擎未就绪与所选模型失效分别提示，不把空模型目录直接等同于从未配置凭据。

新会话尝试发送时先说明需要处理的模型状态，保留草稿、附件和请求身份，配置后不自动发送。所有者的自动/首选调度可明确选择继续交给其他符合条件的 Node；锁定远端不要求本机模型。已提交请求的确认重试及原有远端续聊路径保持不变。进入模型设置或诊断后，可通过“返回会话”回到原草稿。

已完成的普通本机 Task 恢复原会话输入，不再要求新建会话。输入工具栏增加执行模型选择，当前会话选择独立保存；工作流可在执行中为排队的新消息选模型，当前轮的模型不变。普通 Task 在空闲时切换模型，执行中显示当前选择和说明。模型失效时保留原 ID，明确提示重新选择或恢复账号。

延续当前紧凑布局，正文与输入共用内容宽度，模型菜单使用已有分组、搜索与键盘交互。下方 0.1.12/0.1.13 数据为历史记录，不代表本次版本或验收范围。

## 交互

- 默认只保留消息输入和一行工具栏：附件、目录、模型、Node 选择、会话设置、发送。1280px 合成界面中，空输入框从 284.19px 降至 128px。
- 移除常驻的附件配额说明和规划提示；配额与粘贴/拖入提示可在附件按钮悬停时查看，屏幕阅读器仍可读取配额及已选数量。
- 字数统计在接近上限（90%）或超限时显示。输入限制、超限禁止发送和原始草稿不变。
- 文件选中后显示紧凑列表，保留进度、错误、预览、移除和重试。长文件名省略显示，悬停可读全名；列表最多占 136px，更多文件可滚动查看。
- `@` 是统一 Node 入口，选择界面仍支持首选与锁定。选中的目标显示在工具栏，点击可修改模式或清除。
- 审批、执行位置和完成要求放入“会话设置”弹窗；关闭保留设置，Esc 返回入口焦点，目标清除后返回消息输入。设置弹窗不增加输入框高度。
- Enter 发送、Shift+Enter 换行和中文输入法确认维持原规则。普通 Task 的补充执行提醒、只读说明和错误提示继续显示。

范围仅为界面组织和样式；沿用连续会话、队列、草稿及附件路径。共享附件组件在非会话场景仍显示原有文字按钮、配额与数量。没有改动服务、原生应用、依赖、版本或官网。
