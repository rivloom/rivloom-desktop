# 会话历史与回收站

## 0.1.27：紧凑石墨历史栏

历史栏采用石墨色背景和紧凑单行列表。桌面会话行高 30px，标题 14px；当前会话以稍亮的选中底色和稍重标题区分，键盘焦点另有轮廓。宽窗口的默认列宽为 340px，已有保存宽度优先，也可拖动调整。触屏会话行至少 44px，更多按钮保持可见。

标题是主要信息。未完成的会话在右侧显示执行或需要关注的状态；已完成且没有草稿时显示最近更新时间，当天显示时分，其余显示月日。未完成会话的草稿以标题旁图标标记，已完成会话有草稿时右侧显示“草稿”；置顶标记继续保留。

自己发起的会话不重复显示来源标签；他人委派显示来源设备图标，来源待确认显示提示图标。悬停来源图标可查看来源说明，会话顶栏继续显示来源；完整来源和状态保留在辅助标签中。更多按钮的悬停提示提供状态、来源和完整更新时间。

仅当标题确实被截断时，鼠标悬停或键盘聚焦才显示完整标题浮层；短标题不显示重复提示。浮层不会改变列表行高，Escape、滚动或打开菜单会关闭它。鼠标悬停或键盘焦点进入会话行后，更多按钮出现在右侧信息区，标题宽度保持不变。右键或更多菜单提供重命名、置顶/取消置顶和移入回收站；删除仍需确认，运行中或处理中会话继续受保护。

## 会话来源与筛选

来源判断使用实际创建者或发起设备：同一台机器上的其他成员发起的会话属于“他人委派”，远端执行代理的本地创建者不会覆盖原发起设备。缺少足以判断的身份信息时显示“来源待确认”，不默认归为自己发起。这是展示分类，不改变执行权限、队列归属、原有排序或目录分组。

来源筛选仍按设备区分：“本机发起”包含本机其他成员发起的会话，“其他设备发来”按原跨设备来源筛选。 来源筛选不改变上述身份分类。搜索仍支持标题、目录、设备和正文，命中正文时显示匹配摘要并可打开对应位置；筛选、草稿恢复和会话选择继续保留。

## 目录与会话管理

历史栏按工作目录分组，点击目录可折叠；目录标题显示数量，会话在组内对齐，不再靠向右缩进形成层级。本机目录默认显示文件夹名称，右键目录或点击更多按钮可设置或清除别名，完整路径保留在悬停提示与编辑界面。别名仅按本机登录用户保存，不重命名真实文件夹，不合并同名目录或改变其他设备资料，重启后保留；搜索也支持别名和完整目录路径。

会话重命名和目录内置顶按当前用户持久保存，修改名称不影响任务要求与执行身份。回收站恢复保留名称和置顶，永久删除时清除相关偏好。移入回收站入口位于更多菜单；执行、排队或未知状态仍需先停止并等待确认，正常结束的会话仍经确认后移入。窄屏抽屉支持 Escape 关闭，并将 Tab 焦点限制在打开的抽屉内。菜单与操作说明见[右键菜单](CONTEXT-MENUS.md)。

## 回收站数据规则

回收站按移入时间保留三个日历月，月底日期按目标月份最后一天收缩。记录可恢复到原会话，也可单条永久删除或确认清空回收站。后台每小时清理到期记录，应用启动时也检查到期记录。删除中断的条目保留清理日志并自动重试。

归档和清理覆盖工作流、历次执行、本地任务、远端任务、Brain 记录、已结束队列以及相关应用附件副本。共享附件在仍被其他记录引用时保留。项目目录中的文件、用户另存文件、其他机器上的记录、独立引擎缓存及历史备份不随删除清理。

SQLite 中保留最小 ID 墓碑，拒绝已删除创建请求、工作流请求和旧协作消息重放，避免产生重复执行或让已删除会话重新出现。工作区格式从 3 升为 4；不应使用旧版直接打开升级后的工作区。

验证入口：`tests/conversation-history.test.ts` 和 `node scripts/ci-services.ts conversation-history`。后者启动独立服务与官方引擎，模型请求只发往本地测试服务。
