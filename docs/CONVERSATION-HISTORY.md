# 会话历史与回收站

历史栏按工作目录分组，点击目录可折叠；目录在前，会话向右缩进。0.1.8 起本机目录默认显示文件夹名称，右键目录或点击更多按钮可设置或清除别名，完整路径保留在悬停提示与编辑界面。别名仅按本机登录用户保存，不重命名真实文件夹，不合并同名目录或改变其他设备资料；重启后保留。搜索支持别名、标题、完整目录路径、设备名和需求正文。删除入口位于每条会话右侧。执行、排队或未知状态仍需先停止并等待确认；正常结束的会话可直接移入回收站。

回收站按移入时间保留三个日历月，月底日期按目标月份最后一天收缩。记录可恢复到原会话，也可单条永久删除或确认清空回收站。后台每小时清理到期记录，应用启动时也检查到期记录。删除中断的条目保留清理日志并自动重试。

归档和清理覆盖工作流、历次执行、本地任务、远端任务、Brain 记录、已结束队列以及相关应用附件副本。共享附件在仍被其他记录引用时保留。项目目录中的文件、用户另存文件、其他机器上的记录、独立引擎缓存及历史备份不随删除清理。

SQLite 中保留最小 ID 墓碑，拒绝已删除创建请求、工作流请求和旧协作消息重放，避免产生重复执行或让已删除会话重新出现。工作区格式从 3 升为 4；不应使用旧版直接打开升级后的工作区。

验证入口：`tests/conversation-history.test.ts` 和 `node scripts/ci-services.ts conversation-history`。后者启动独立服务与官方引擎，模型请求只发往本地测试服务。
