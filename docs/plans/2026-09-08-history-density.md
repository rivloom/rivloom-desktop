# 历史会话单行与来源配色

先补测已安装桌面端的崩溃恢复、实际半传文件恢复、另一台机器通知和输入法，再按用户要求压缩历史会话。

- 自己发起的会话使用浅底，别人发来的会话使用深蓝底。
- 每条会话改为约 40px 单行，移除重复的来源说明行；保留来源图标、标题、状态和选中边线。
- 已完成和已结束状态使用简短图标，处理中及待处理状态保留文字。悬停提示和辅助阅读标签提供完整标题、来源与具体状态。
