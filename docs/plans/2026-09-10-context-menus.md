# 目录、会话和文件右键菜单

用户要求三类菜单中的全部操作。沿用现有侧栏、确认弹窗、文件授权和桌面原生接口。

1. 提供共用菜单：右键、Shift+F10/Menu 键、更多按钮；方向键、Home/End、Enter、Esc、Tab；边缘避让、点击外部关闭和焦点恢复。
2. 目录：设置别名、复制完整路径、打开文件夹。只对有本机完整路径的目录启用路径操作；保留远端别名能力。
3. 会话：用户级持久重命名、目录内置顶/取消置顶、现有带确认的回收站操作。改名不改变执行请求、路由和任务身份；回收站恢复保留偏好，永久删除一并清理。
4. 文件：打开、打开所在目录、另存为、复制路径。复用授权与完整性校验；仅完整且可保存的本机副本可操作。原生打开使用 Windows 文件关联，无 shell 字符串拼接。
5. 验证存储隔离/重启/删除清理、原生路径与权限契约、生产 UI 的鼠标/键盘/触屏、失效与运行中保护、中英文窄窗，再完成版本交付。用户实体安装与真实模型测试继续暂停。

本地完成：359 项逻辑、26 项原生、10 项隔离服务、17 项菜单 UI、10 项更新 UI、65 项 CI helper、构建与版本一致性通过。0.1.10 源码和发行说明就绪，正式发行须继续通过同提交的云端 CI、独立安装和公开签名校验。
