# 双机实测后的修复

2026-09-07 在本机 192.168.5.33 和 192.168.5.29 的已安装 0.1.4 客户端完成五项真实模型测试：本机、正向附件任务、暂停与恢复队列、反向 `@Node` 派发、Brain 自动选择空闲节点。原配对及历史记录保留，测试执行开关恢复关闭。

发现两处问题：

1. 首次定向任务的附件可能先于任务邀请到达，接收端拒绝文件，发送端永久显示失败，需要手动重试。文件传输应等待原任务被认证确认接收；同一节点的其他可发送文件不应被未确认任务阻塞。Brain 提交也要遵守相同顺序。
2. 验收时远程摘要被状态标签覆盖。验收后应保留最后一条模型正文，状态标签继续单独展示，并保留现有脱敏及长度限制。

验证顺序：先用确定性的协议回归复现首次发送问题；验证定向与 Brain 文件握手时序、未确认任务不阻塞其他文件、验收前后正文一致；运行隔离服务和正式 OpenCode 引擎的文件往返验收；构建新的本地候选安装包。已安装双机的结果与候选包验证分开记录。
