# 0.1.8 目录别名与侧栏层级

用户依据两张截图要求：工作目录可自定义别名；会话向右缩进，目录层级更突出；移除“历史会话”和总数量一栏；缩小并上移顶部本机图标/在线信息区；应用窗口标题仅为 Rivloom。完成后发布 0.1.8，由用户验证 0.1.7 的更新流程。

1. 目录分组保留现有稳定 key，显示本机用户设置的别名；未设置时本机目录使用末级目录名，完整路径保留在提示及编辑界面。远端显示已有设备/目录信息。别名不改真实目录、项目身份或设备对外资料，保存、清除、重启及搜索均可用。
2. 用现有 SQLite app_settings 按当前用户保存别名，通过已鉴权 UI 偏好接口写入并随 bootstrap 刷新；单项更新不覆盖其他目录，拒绝无效键、超长/控制字符和伪造用户字段。沿用数据格式 4。
3. 目录行采用更清晰的字重与紧凑编辑入口，会话作为向右缩进的子列表；移除整体标题计数行。顶部区域减少内边距及头像尺寸，保留名称、在线状态和编辑入口；原生初始/切换语言后的窗口标题及 HTML 标题统一为 Rivloom。
4. 覆盖别名持久化、用户/目录隔离、重置、无效写入、搜索及原有历史行为；真实浏览器检查中英文、长别名、保存失败/重试、键盘、200–480 像素侧栏及手机抽屉。继续运行 0.1.7 的安装交接回归，确保升级体验不回退。
5. 同步 0.1.8 版本与发行说明，完成该提交 CI、隔离安装、Release、公开完整包下载及旧公钥签名验证，再同步官网。用户安装版和真实付费模型不用于测试。
