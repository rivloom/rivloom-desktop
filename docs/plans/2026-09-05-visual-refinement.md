# 官网与桌面视觉修订

2026-09-05，用户授权官网和桌面端进一步美化，当前只调整审美，不调整功能；完成后两个仓库均提交并推送 Git。本次授权取代此前桌面推送待确认的状态，不扩大为公开安装包发行或自动安装。

## 视觉方向

延续用户提供的正式蓝色 Logo。官网采用有层次的标题、留白和完整产品画面，改善首页段落节奏与内页阅读；桌面采用浅冷灰蓝背景、清楚的文字层级、钴蓝主操作与深蓝外来会话，统一输入框、按钮、设备状态和设置页面。保留状态颜色的语义和可见键盘焦点。

桌面显示使用原始 PNG：完整字标、渐变图形与白色图形保存在 `src/assets/brand/`，通过 SVG viewBox 缩减原图外围留白，保持像素和比例。产品安装标识与现有数据保持原值。

## 范围与验证

- 只调整 CSS、静态装饰与品牌素材，不改变控件、文字含义、任务/队列/协作/审批、网络协议或数据格式。
- 官网继续使用原有链接、公开下载状态、隐私/RUM、安全响应头和生产收录规则。
- 在新建隔离目录中预览桌面界面，检查新会话、既有会话、配对节点、队列、设置、窄窗口与主要交互；不复用正式客户端数据或凭据。
- 执行两个仓库的构建和适用检查，独立审查行为代码差异；分别提交推送，核对实际 GitHub CI 及官网自动部署。

本轮本地验证已完成，细项见 [UI-HANDOFF](../UI-HANDOFF.md) 与 `.data/verification/visual-refinement-20260905.json`：桌面前端构建和独立差异审查通过，1282/962 宽真实隔离浏览器检查及主要交互通过；官网构建通过 21 个 Astro 文件零诊断、9 页及 235 个引用检查，并检查 1440/390/320 宽页面。只有 CSS、品牌表现层和文档变更。云端结果按两个仓库的实际推送提交分别核对。

本次不以视觉修订代替签名发行、客户端升级或双物理机验收。官网继续使用已标明预览性质的原始真实截图，不重绘或伪造产品状态。
