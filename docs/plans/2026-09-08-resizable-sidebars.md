# 两侧栏拖动宽度与收尾提交

用户要求历史会话栏和配对机器栏都可以拖动，完成后收尾提交。沿用现有视觉样式，在左栏右边缘和右栏左边缘添加可拖动分隔线，调整整栏宽度。手机抽屉保持现有布局。

- 宽度受栏内可用性和中间会话最小宽度约束，窗口变窄时自动收紧，恢复窗口后使用用户保存的宽度。
- 支持鼠标/触控指针、键盘方向键、Home/End、Escape 取消拖动与双击恢复默认。
- 用户宽度保存在本机用户设置中。桌面后端端口会变化，因此不用按网页端口隔离的 localStorage 承担重启持久化。
- 拖动时只更新布局，松手后保存；保持当前会话、草稿和独立滚动。
- 只做这次改动所需的逻辑、构建与合成界面验证；此前用户暂缓的实机、断网和性能边界继续暂缓。
- 验证后更新交接记录，审阅并提交本轮累计的产品改动；不推送或公开发布。
