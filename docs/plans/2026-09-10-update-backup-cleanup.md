# 更新成功后的备份清理与会话删除入口

用户要求会话删除按钮仅鼠标悬停时显示，并明确选择“升级成功后全部删除”更新备份。

1. 桌面悬停或键盘焦点进入会话行时显示删除入口，隐藏时不可鼠标点击；触屏保留可见入口，不改变删除确认或运行任务保护。
2. 前端只有在桌面身份、完整工作区和引擎就绪后才发送启动成功回执；原生再次确认自有后台存活，和更新操作互斥。更新恢复标记保留到成功回执与清理完成。
3. 清理范围仅为实际应用数据目录 `.updates/backups` 内符合更新备份命名和版本约束的目录。新版正常启动后删除目标版本不高于当前版的备份（包括旧版遗留及中断副本），未来版本、失败启动及无法确认的目录保留；不接触当前数据库、项目或另存文件。
4. 清理前验证绝对路径和目录边界，拒绝重解析点/符号链接与异常清单；文件占用导致的失败可重试，不阻塞工作区。覆盖旧备份、未来版本、失败恢复、越界链接、异常内容、部分删除和重复回执。
5. 通过原生测试、生产浏览器悬停/焦点/触屏及启动回执检查、更新交接回归，再准备下一版交付；不在开发测试中操作用户安装版或现有备份。
