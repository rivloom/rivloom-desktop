# Rivloom 0.1.21

本版正在准备，尚未正式发布。下载及各平台实际发布状态以[官网](https://rivloom.com/download/)为准。

## 聊天与输入

- 附件和设备选择分别放在输入框左右上沿，作为框外的独立图标；选择后显示附件数量或设备名称，正文区域更简洁。
- 支持向聊天区域拖入文件，沿用附件上传通道。文件卡片展示上传进度、失败重试、预览与移除；上传和移除未完成时阻止发送。
- 引用显示为独立、可移除的卡片，不再把引用文本填进正文输入框。引用随草稿恢复，发送失败后可重试，历史消息和待执行消息编辑保持引用与正文分开显示。
- 上沿选择设备保留正文，支持首选、锁定和清除；修复按 Escape 关闭后设备菜单重新出现的问题。
- 收紧聊天间距，统一消息操作，将用量、执行记录和文件入口收纳到辅助区域。

## 主界面与设置

侧栏增加低频功能菜单与可折叠的队列/设备区域，新会话提供可编辑的任务示例。设置按模型、执行与文件夹、设备、诊断整理，精简模型接入过程，增加保存反馈与诊断跳转。知识管理的筛选、空态和编辑布局一并调整。

## 范围

执行中发送的新要求仍进入待执行队列；本版不包含“立即插入当前流程”。问题卡片回答与普通排队消息继续分别处理。旧版普通会话的停止后续聊逻辑保持。

固定核心仍为 **1.18.31-rivloom.9b07cf442a7e**，SDK/plugin **1.18.31**，Node.js **24.19.0**，没有追踪 Runtime 最新提交。目标平台仍为 Windows / Linux x64，ARM64 暂缓；本轮桌面界面改进不等于 Linux 已发行新版。

本地已覆盖合成数据的浏览器交互、相关逻辑回归、前端构建，以及此前体验包的静态文件和隔离后端启动检查。0.1.21 正式候选的云端安装、原生 WebView2/资源管理器拖放及公开分发验证尚未完成，不以旧版或体验包验收替代。
