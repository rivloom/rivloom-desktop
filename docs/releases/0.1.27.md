# Rivloom 0.1.27

## 历史会话栏

- 使用石墨色侧栏和紧凑单行列表：桌面行高 30px，标题保持 14px，同屏显示更多会话。
- 重要执行状态、草稿、委派来源和置顶标记保留；已完成的会话显示更新时间。
- 更多操作在悬停或键盘聚焦时出现，标题宽度保持稳定。仅对被截断的长标题显示完整提示。
- 宽窗口默认侧栏列宽为 340px，已有保存宽度继续优先；可继续拖动调整。触屏会话行保持至少 44px。
- 保留项目分组、目录折叠与别名、全文搜索与匹配定位、筛选、草稿恢复、重命名、置顶及回收站。删除仍需确认，运行中的会话继续受保护。
- 修复窄屏会话抽屉的 Escape 关闭和 Tab 焦点循环。

## 平台与升级

本轮不修改节点协议、模型连接或用户数据格式。Windows x64 提供桌面安装器与签名更新频道；Linux x64 保持同版本无界面节点与手动升级，不包含桌面侧栏。ARM64 未发布。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 保持 `1.18.31`，Node.js 保持 `24.19.0`。

源码与界面验证已完成；正式安装器、公开下载和官网同步状态以本次发行验收及实际下载记录为准。
