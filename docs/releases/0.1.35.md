# Rivloom 0.1.35

本版面向 Windows x64 增强工作台上下文引用、产物差异审核、多设备拓扑遥测与 Skills/Wiki 主动协作体验；随包执行核心保持 OpenCode 1.18.33 与 Node.js 24.19.0。 [正式下载](https://rivloom.com/download/)

## 工作台深度交互与上手引导

- 输入区支持 `@` 模糊引用工作区文件与设备路由、`#` 模糊引用 Wiki 条目与 Skills，支持键盘导航与中文 IME 合成保护，遵循按需引用不整库注入。
- 右侧检查器「产物」页支持按轮次筛选交付物，并可将改动文件或具体 diff 片段一键引用回输入框继续追问与微调。
- 多设备 SVG 拓扑节点呈现真实 CPU/内存负载、可用槽位与本机实时流速（缺失或未知数据保持 `—`，不虚构零值），并支持在节点详情中快速切换路由或跳转队列控制。
- 任务驾驶舱在尚未配置模型或工作文件夹时提供可跳过的两步轻量上手引导，复用既有配置流程。

## Skills 与 Wiki 主动协作

- 支持在已完成会话轮次或已确认的「会话上下文」中一键预填并沉淀为项目 Wiki 或 Skill 模板草稿，仍由用户审校保存，保持默认本机私有、手动分享与不执行脚本边界。
- 知识库新增左侧分层分类大纲、私有/共享/类型筛选与更清晰的分享范围确认；会话与检查器侧展示本次任务实际按需读取的 Wiki 与 Skill 记录。
