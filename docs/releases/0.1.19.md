# Rivloom 0.1.19

**发行候选：** 本页说明本版源码中的行为。公开安装包须通过同提交 CI、安装验收、公开下载和签名核验后提供；各平台以官网下载记录为准。

## 会话与执行上下文

执行中展示模型提供的思考与工具活动。OpenCode 压缩继续执行时，Rivloom 恢复当前执行所需的工作流和权限规则；规则记录绑定任务、账号、会话和执行轮次。

同一会话保留带来源版本的目标、约束、决定与进度，续聊和节点交接传递有界状态。模型推断与用户确认分开，较新的要求可替代旧推断，模型不能把推断升级为用户授权。

历史按需搜索并读取原文，每页最多 32 KiB 的 UTF-8 JSON，包含正文、元数据及转义。分页保留 UTF-16 偏移和来源版本，通过返回的 nextOffset 继续读取。支持该能力的节点不再默认重复携带累计对话附件；旧节点保留既有附件兼容路径。远端读取只允许当前受信任、已接受该执行的目标节点，结束或撤销后拒绝新的读取。

## 队列、模型和连接

本机等待、暂缓任务可以取消排队；失败任务在确认引擎停止后结束并移出队列，历史仍保留。新安装不再隐式选择 OpenCode Zen 免费模型，用户已显式接入的账号继续保留。节点发现降级时，只要已配对节点的认证通道仍就绪，仍可按原权限执行任务。较大的中文历史页使用协作响应预算，握手与控制响应仍有独立限制。

回答下方的引用操作显示“引用到输入框”，便于识别；引用仅进入草稿，不自动发送。

## 运行环境与边界

Windows x64 和 Linux x64 源码使用 Rivloom 固定源码构建的 OpenCode **1.18.31-rivloom.9b07cf442a7e**，核心固定为 **9b07cf4**；SDK/plugin 为 **1.18.31**，Node.js 为 **24.19.0**。ARM64 暂不发布。安装包包含完整运行环境，应用内签名更新使用既有公钥；Windows Authenticode 代码签名尚未配置。

32 KiB 是单次历史读取预算，不是模型上下文窗口、历史总容量或用户输入上限。历史仍然保留，长期记忆/Wiki 的进一步联通、专用上下文编辑界面以及完整存储维护不属于本版。真实模型执行中压缩与执行途中多机重启仍有待专项验收，不能以合成模型测试替代这些工况。

下载与各平台实际发布状态见[官网](https://rivloom.com/download/)，使用说明见[随包说明](../../DESKTOP-README.md)。
