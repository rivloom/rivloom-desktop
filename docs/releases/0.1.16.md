Rivloom 0.1.16

- 开发界面的“执行模型”支持按服务商分组、名称排序和搜索，同名模型可按不同 Provider 分别选择。
- 模型菜单展示引擎声明的上下文容量与图片输入能力，支持键盘选择、输入法和窄窗口。
- 模型接入默认展示“账号登录”，并常驻 API Key、自定义服务入口；支持搜索厂商和 ChatGPT 等登录方式，登录按钮直接显示厂商名称。
- 自定义服务支持保存后继续添加另一服务，并通过已接入标签切换编辑；补齐目录加载、空结果和重试提示。
- 接入界面适配中文、英文和窄窗口，保留工作区创建者权限、任务运行锁定及额度确认。
- 内部交接、开发计划和原始验证记录改为仅本地维护，公开说明、构建依赖及许可文件继续分发。
- 当前支持 Windows x64。厂商登录方式与模型能力来自随包引擎目录；账号权限、额度和实际可用模型以厂商为准。
