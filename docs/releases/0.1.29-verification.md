# Rivloom 0.1.29 发行验收

Windows / Linux x64 0.1.29 已发布，官网、公开下载与 Windows 签名更新已核验。源码 [e09986fac8d1fdfe213d60f09a6b6f722464c938](https://github.com/rivloom/rivloom-desktop/commit/e09986fac8d1fdfe213d60f09a6b6f722464c938)，固定核心 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 1.18.31，Node.js 24.19.0。

## 本版变化

包含模型按任务语义选择设备、输入区停止、失败与停止后的消息续接、远端取消回执收尾及会话界面整理。人工暂停、上下文准备失败和未确认停止仍保留相应保护；历史失败任务不会因升级自动重跑。详细行为见[版本说明](0.1.29.md)。
