# Rivloom Linux 0.1.24

安装包与实际发布状态以[官网下载页](https://rivloom.com/download/)及[Linux 下载记录](https://downloads.rivloom.com/releases/linux/latest.json)为准；本文件不替代本版发行验收。

Linux x64 与 Windows 0.1.24 使用同版服务端源码，增加 Node 本地执行任务的短时输入与输出活动采集、按模型连接分项和知识操作状态。输入使用最近 60 秒新确认 token 均值，输出使用最近 3 秒真实流式文本估算；未知或不完整数据不显示为 0。接口仅向节点所有者开放，不增加模型调用或上传遥测。

Linux 发行物仍为无桌面界面的 x64 执行节点，不包含 Windows 侧栏动效、文件预览窗口或原生导出界面。保留现有 SSH、信任、项目、模型与任务执行方式，ARM64 本版不提供正式下载。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin `1.18.31`，内置 Node.js `24.19.0`。继续采用手动升级：先停止节点并保留数据目录，再按[Linux 节点说明](../LINUX.md)安装与核对校验值。校验值用于确认文件一致性，不等同于发行签名。

具体交互与数据限制见[0.1.24 更新说明](0.1.24.md)。原生构建、包内启动和公开下载验收结果在发布完成后记录。
