# Rivloom 0.1.33

本版修复 Windows x64 的设备间文件传输、任务状态和更新恢复。 [正式下载](https://rivloom.com/download/)

## 文件传输

- 接收端在最后一块写盘后退出时，重连会从已确认的进度恢复。文件通过完整性校验后才会显示为完成。
- 拒绝仅大小写不同的重复附件编号，防止 Windows 上已有文件被覆盖。单个源文件无法读取时，其他文件仍可继续发送。
- 重试取回时切换会话，取回完成后会释放名额并停止轮询。

## 任务与更新

- 引擎退出后，旧查询的结果不会将已中断的任务误报为完成。
- 更新安全检查失败且后台已退出时，客户端会重新启动当前版本。安装仍须通过安全退出检查。
