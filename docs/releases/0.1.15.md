Rivloom 0.1.15

- 共享 Skills：登记本机 Skill 文件夹，查看并管理分享给哪些 Brain；其他成员通过 Brain 搜索和按需读取来源最新版。
- 渐进式读取：先查看用途摘要，再读取 Skill 说明和所需支持文件；每个任务固定首次读取版本，新任务获取当前版。执行仍沿用任务审批。
- Wiki 记忆：支持分层分类、项目范围、编辑历史和按需加载；默认仅本机可见，手动分享给 Brain。
- 本机主说明与工作目录说明：支持本机 AGENTS.md 及目录 AGENTS.md / agent.md，按任务和授权范围读取。
- 记忆整理生成分类索引并标记完全重复正文，保留原文与历史；不额外调用模型，也不包含独立 AI 后台语义重写。
- 完善随包许可证、贡献与安全说明，强化正式发布来源和外部 PR 的权限边界。
- 共享知识库需要相关 Node 与 Brain 升级至支持该能力的版本，来源须在线且保留授权。Windows x64。
