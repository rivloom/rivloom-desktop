# Rivloom 0.1.24

安装包与发行状态以官网及对应发行记录为准。

## 紧凑侧栏与 Node 活动

- 侧栏底部的入口、字体和间距更紧凑，保留更多历史会话空间。模型连接下方显示当前 Node 的输入、输出与运行数量；点击名称打开配置，点击状态区查看各连接分项。
- 汇总当前 Node 本地执行的多个会话及接收的委派任务，不将交给其他 Node 执行的任务混入本机流速。个别任务失败单独提示，其他正常任务继续显示活动。
- 输入为最近 60 秒内新确认输入 token 数的每秒均值，不代表模型预填充速度。输出为最近 3 秒真实流式文本的 token 估算，以 `≈` 标注。未提供、过期或覆盖不完整的指标隐藏；不会用历史消息、工具结果或虚构的 0 补齐数据。

## 操作反馈

- 知识入口区分目录更新、共享内容读取、保存和整理等实际操作；执行时显示活动，完成后短暂确认，部分失败可展开查看原因并关闭提示。切换页面仍保留进行中操作的状态。
- 项目文件的读取、解析、保存、复制及桌面导出提供反馈；待办数量因新增事项上升时徽标轻弹一次；设备连接和执行状态变化提供轻量反馈。
- 小波形、图标与状态变化集中在对应入口，空闲或页面隐藏后停止持续动效，并遵循系统减少动态效果设置。

## 数据口径与支持范围

活动监视只面向当前 Node 的所有者，使用本机内存中的短时状态，不增加模型请求或上传遥测。连接分项不是模型服务商账单，输入均值和输出估算也不等同于供应商测得的推理吞吐量。服务重启会清空短时活动记录；输入、输出任一项缺少可靠数据时可分别隐藏。

Linux x64 无界面节点使用同版服务端活动采集与知识操作反馈；侧栏动效和原生文件操作属于 Windows 桌面客户端。此次不新增跨设备汇总监视、历史流速报表或知识同步的虚假百分比进度。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 保持 `1.18.31`，Node.js 保持 `24.19.0`。真实内网模型的计量上报与长任务质量仍需按实际服务验证，测试使用确定性合成数据，不作为真实模型性能成绩。
