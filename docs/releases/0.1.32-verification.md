## 验收范围

本地用与正式源码相同的文件构建前端，17 个产物共 4,652,526 字节，与此前通过本地桌面界面验收的前端逐文件一致。正式安装后的运行时与品牌资源由候选安装流程检查，独立公开下载核验覆盖完整文件和更新签名。

本轮安装验收覆盖托管 Windows x64 环境下的全新安装。实体多机局域网、实际 OAuth 和付费模型、完整跨版本升级矩阵，以及正式安装包的原生窗口视觉均未纳入本轮。此处的签名结果指应用内更新验签，Windows Authenticode 发布者签名尚未配置。
