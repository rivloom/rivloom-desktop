## 功能与验证边界

本版新增 PDF、DOCX、XLSX 及文本/表格预览、小型 UTF-8 文本编辑、随时可打开的模型连接配置、多连接切换、系统文件操作，并修正待办与会话往返和全界面交互。具体支持范围见[版本说明](0.1.23.md)及[办公文件与模型连接](../OFFICE-WORKSPACE.md)。必要解析依赖随包提供；模型调用需要能够连接用户配置的服务。

界面整改阶段的中英文、宽窄窗口、键盘、弹窗、待办往返、草稿、配置和办公预览验收沿用已核对源码的结果；包括原生 WebView2 中发现问题后修正并复验的记录。本次云端构建及正式包静态验收重新绑定 0.1.23 源码，官网展示直接加载该正式包前端。真实内网模型的长任务质量、复杂办公材料完整性、实体 Linux 多机、最低 glibc 发行版、Linux WebKitGTK 桌面视觉、高 DPI/屏幕阅读器及完整跨版本升级矩阵，未在本轮增加验收。Linux 是无 GUI 节点。

固定核心保持 1.18.31-rivloom.9b07cf442a7e，SDK/plugin 1.18.31，Node.js 24.19.0。合成模型任务验证工具与流程能力，不代表用户实际内网模型已经适用。
