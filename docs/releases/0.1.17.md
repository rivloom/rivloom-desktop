## 模型账号与分组

- 同一厂商可添加多个账号，并为每个账号设置别名，例如“工作套餐”和“个人套餐”。各自保存 API Key 或完成该厂商支持的 OAuth 登录；OpenCode Go 使用 API Key 接入。
- 新增账号使用独立官方引擎与凭据目录。选择模型时按厂商和账号别名区分，任务、停止、恢复及审批始终关联原账号。原有账号和会话保持兼容。
- 模型菜单增加醒目的分组标题、账号别名和模型数量，支持折叠、展开全部、搜索自动展开及键盘操作。
- 模型接入可直接保存或登录，移除重复的额度确认勾选框；主动模型连接测试仍保留单独确认。

多个账号需要分别具备相应服务权限；本版不自动轮换账号、合并额度或共享套餐。真实厂商账户授权和套餐可用性由服务商决定，本轮验证使用隔离服务和本机合成模型。操作方法见[模型接入说明](../MODEL-ACCESS.md)。

## 界面文字

主界面采用系统字体，调大会话标题、输入占位文字、模型和目录控件，增加文字对比度。品牌标签继续使用按 SIL OFL 1.1 授权的 Manrope；系统字体仅调用设备已安装资源，不随包复制。详见[字体与许可说明](../BRAND.md)。

## 兼容与发行

本次保持现有 Node 协议与能力协商版本；新增账号元数据与任务引擎关联使用附加存储，默认账号和既有会话仍使用原引擎。升级前正常退出旧客户端，再安装新版本并保留原数据目录。

发布前使用隔离数据和官方引擎实测了 0.1.16 / 0.1.17 双向直接任务、4 种提交方/规划方/执行方混合组合；升级旧服务后，原节点身份、模型配置、任务状态和会话关联保持。此验证没有改动用户安装目录或真实项目。原有协议兼容不代表任意后续版本均兼容。

本版发行平台为 Windows x64，随包 Node.js 24.19.0、官方 OpenCode / SDK 1.18.25。本地逻辑、协议、引擎及相关服务检查通过，35 组界面检查覆盖账号接入、模型分组与字体；正式安装包验收结果见本页顶部。可用安装包以[官网下载页](https://rivloom.com/download/)为准。
