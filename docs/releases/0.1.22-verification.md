## 功能与验证边界

本版包含聊天与侧栏视觉、动效和图标导航、队列栏空闲收起/有执行项时展开、菜单鼠标与键盘焦点修复、Logo 旁实际版本号与独立关于按钮，以及“回到最新”按钮按下保持居中。附件、引用、排队发送和执行授权协议保持；消息仍按顺序排队。核心固定为 1.18.31-rivloom.9b07cf442a7e，SDK/plugin 1.18.31，Node.js 24.19.0。

界面鼠标、键盘、中英文与宽度检查沿用本次界面修复阶段的隔离合成验证。本地版本/覆盖检查、85 项 CI 自检、696 项逻辑测试、双语/类型及生产构建通过，云端门槛按上表对应源码独立运行。原生 WebView2 视觉与资源管理器实际拖放、Linux WebKitGTK 桌面视觉、真实模型/跨设备引用、长会话性能、高 DPI/屏幕阅读器、实体 Linux 多机、断电及完整跨版本升级矩阵未在本轮覆盖。Linux 产物是无 GUI 命令行执行节点。官网浏览器自动化服务（CUA）本轮不可用，因此没有新增官网截图或浏览器视觉验收；HTTP 页面、下载契约和命令核验不替代视觉检查。
