## 关闭到托盘与直接退出

关闭窗口后保留后台执行，首次显示说明，点击「知道了」后记住选择。托盘图标、菜单和再次启动均可恢复工作区。右键「退出 Rivloom」会停止本应用后台并直接退出，不再弹出二次确认或重新显示窗口；窗口最小化按钮保持 Windows 默认行为。

## 局域网连接检测与修复

「设备与模型」和「连接诊断」会检查当前网络类型、实际通信程序、监听及有效防火墙规则。缺少适用规则时，可点击「允许局域网连接并复测」，由 Windows 管理员授权为当前安装配置本地子网规则；公用网络需要用户明确同意。操作不会关闭防火墙、更改网络类型或绕过配对身份验证。

修复后重新发现设备并检查连接，不自动配对或派发任务。修正 Windows 原生资源路径与安装路径的标识差异，以及系统打包应用规则被误判为允许桌面通信的情况。规则按安装路径管理，更新保留已有授权，卸载只清理应用拥有的规则。

本机与 Windows Server 2025 公用网络实测已覆盖规则缺失、用户修复、加密连接恢复、应用重启自动重连、授权保留及规则范围核对。系统授权取消、带规则升级/卸载等交互仍需单独验收，不据连接成功宣称全部环境通过。

## 任务等待原因与诊断摘要

步骤状态区分执行、排队、准备材料、等待前置步骤和执行待确认。可查看设备连接、执行配置、工具报告与硬件条件；信息缺失或过期时显示待确认。

队列回执区分等待、暂缓、已获执行槽和拒绝。连接断开或执行不确定时不显示失效排位。可复制诊断摘要，省略任务正文、设备名称和路径；读取失败保留的结果标为旧记录。刷新诊断不重新派发任务，已接收的执行仍保持原设备和尝试记录。

## 兼容与运行环境

继续支持 Windows x64，随包 Node.js **24.19.0**、未修改的官方 OpenCode / SDK / plugin **1.18.25**。本版没有切换自研引擎，也没有更改现有配对、节点协议或模型账号机制。已有远程任务验收继续有效，复杂规划和模型输出质量仍取决于具体场景。

安装器包含完整运行环境，无需单独复制 runtime 文件夹。应用内更新沿用现有公钥与签名频道；Windows Authenticode 代码签名尚未配置。操作说明见[随包说明](../../DESKTOP-README.md)，下载见[官网](https://rivloom.com/download/)。
