# Rivloom 0.1.31

本版是 Windows x64 小型更新，改进版本确认提示并整合构建发布流程修复。正式版本可用性以官网下载页的实际记录为准。

## 桌面更新提示

- 检查更新确认无需升级时，同时显示当前安装版本，例如“Rivloom 0.1.31 已是最新版本。”，便于核对升级结果。
- 中文和英文界面均显示实际读取到的版本号；无法读取有效版本时保留原有提示。

## 构建与发布

- Windows 自动候选在同一源码的三组检查全部通过后开始打包，避免其他检查尚未结束时发生等待超时。
- 失败检查重跑成功后重新判断打包条件，并避免重复构建已经成功的同源码候选。
- 自动发布先核验官方已签名版本。保持已发布版本号的维护提交只运行源码检查，正式新版本继续经过安装、公开下载和原公钥签名验证流程。

执行核心保持 OpenCode 1.18.33，Node.js 保持 24.19.0，依赖版本及应用内更新信任公钥沿用既有配置。
