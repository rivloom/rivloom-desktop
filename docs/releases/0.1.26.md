# Rivloom 0.1.26

正式发行及公开下载核验已完成，详见[0.1.26 发行验收](0.1.26-verification.md)。

## 升级备份

- 缩小应用内更新的备份范围：公共引擎和各独立模型账户的缓存、临时文件不再重复复制。
- 核对随包插件依赖的完整文件集合、长度、SHA-256 和精确版本声明；确认可以从安装包离线重建后，跳过这些生成文件，减少大量小文件的复制与落盘。
- 自定义插件、修改过的依赖、历史遗留文件，以及缺失或无法验证的清单继续完整备份。每个引擎独立判断，保留会话、账号、配置、附件和资源数据。
- 旧安装补充依赖清单时保留已有用户文件；辅助清单生成失败不会阻止引擎启动。保持后台安全退出、备份完整性验证和成功启动后的备份清理规则。

## 生效范围

从旧版更新到 0.1.26 时，备份仍由旧版执行。这项优化会在安装 0.1.26 后发起的后续应用内更新中生效。它不删除当前应用文件，也不提供自动还原或跨版本回滚。

Windows x64 提供桌面安装器与签名更新频道。Linux x64 继续提供无界面节点与手动升级；包含同一套插件依赖清单准备逻辑，没有桌面更新备份流程。ARM64 未发布。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 保持 `1.18.31`，Node.js 保持 `24.19.0`。本版发布结果以正式下载记录与发行验收为准。
