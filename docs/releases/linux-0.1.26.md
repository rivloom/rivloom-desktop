# Rivloom Linux 0.1.26

正式发行及公开下载核验已完成，详见[0.1.26 发行验收](0.1.26-verification.md)。

Linux x64 无界面节点随桌面版本同步至 0.1.26，核心、Node.js 和 SDK/plugin 保持不变。

- 为随包插件依赖记录逐文件长度与 SHA-256 清单；已准备好的旧引擎补充清单时保留用户修改和自定义插件。
- 可选清单写入失败不会阻止已有引擎使用；必要的依赖或配置准备失败仍明确报错。

Linux 沿用手动停止节点、更换程序、保留数据目录的升级方式，没有 Windows 桌面的应用内备份与安装流程。仅发行通过本次原生构建和运行检查的 x64 包，ARM64 未发布。

公开下载及安装命令见[Linux 使用说明](../LINUX.md)。校验和用于核对文件完整性，不等同于数字签名；正式产物以本次下载记录和验收结果为准。
