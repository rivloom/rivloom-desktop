# Rivloom 0.1.32

本版更新 Windows x64 桌面的会话、设置和常用工具。正式下载与版本状态见 [Rivloom 下载页](https://rivloom.com/download/)。

## 会话与设备协作

- 当前会话用一条进展入口汇总执行和文件传输。展开后可以查看阶段、参与设备、传输方向和每组文件的确认字节。
- 发送端、路径和接收端的反馈随新确认字节出现。任务完成后，进展收为过程记录，正文和成果仍可直接查看。
- 手动展开的内容和正在阅读的文字在状态更新时保持在原处。浅色、深色和跟随系统可以从外观菜单切换，动效遵从系统的减少动态效果设置。

## 设置与常用工具

- 重新整理模型接入、执行与文件夹、设备连接和诊断页面，统一表单、选中状态、键盘焦点和窄窗口布局。
- 更新知识与记忆、待办、回收站、项目文件和提示词模板界面，并统一侧栏、快速访问与菜单的图标样式。

执行核心沿用 OpenCode 1.18.33，随包 Node.js 为 24.19.0。
