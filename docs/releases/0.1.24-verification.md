## 功能与验证边界

本版新增当前 Node 的侧栏活动反馈：模型连接显示近 60 秒新确认输入用量的平均速率，以及最近 3 秒文本和推理输出的 ≈ 估算速率；数据缺失、过期或汇总不完整时隐藏汇总，仍可查看有效的连接明细。它不表示模型 prefill 速度、计费或账户额度，也不汇总其他 Node。知识反馈覆盖真实读取、保存、目录刷新、整理和分享操作，保留失败或部分失败，明确清除只关闭提示、不重试操作；不声称全设备同步完成。文件操作在切页后继续反馈，待办只在新事项导致数量增加时轻弹一次，设备状态使用新鲜的连接证据。隐藏页面或减少动态效果偏好会收敛动画。 详细范围见[版本说明](0.1.24.md)。

本轮活动界面开发检查和正式包静态核验不替代新增原生 WebView2 视觉验收；真实模型计量准确性、真实内网模型长任务质量、实体 Linux 多机、最低 glibc 发行版、高 DPI/屏幕阅读器和完整跨版本升级矩阵未在本轮增加验收。Linux 是无 GUI 节点。固定核心为 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 1.18.31，随包 Node.js 24.19.0。 合成模型测试验证工具与数据流程，不代表用户实际模型已完成业务验收。
