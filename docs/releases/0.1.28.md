# Rivloom 0.1.28

## 本机模型速率

- 主界面在“模型连接”右侧同一行显示速率，窄侧栏优先显示输出；连接配置和速率详情可分别打开。
- 尚无可靠采样时显示 —，详情区分空闲、等待输出、数据不完整和暂不可用；活动接口恢复后自动更新。
- 模型请求等待流式订阅真正就绪后再发送，修复短回复起始增量可能丢失的问题。断线恢复观察不会重复提交任务。
- 短回复完成后保留原 3 秒窗口内的已测输出，让一句话回复也能被界面轮询看到；运行和生成计数立即归零，采样到期后不填假 0。

速率只统计本机执行的模型调用，远端执行不计入。输入是近 60 秒新确认用量的平均速率，输出是近 3 秒文本与推理增量的估算速率，并非供应商精确瞬时吞吐量。首个增量到达前显示未知值；完整数据可在详情查看。

## 平台与升级

Windows x64 使用桌面安装器与既有签名更新频道。Linux x64 无界面节点同步任务订阅和采集修复，继续手动停止节点、更换程序并保留数据目录。ARM64 暂不发布。

本版不修改节点协议或用户数据格式。固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin `1.18.31`，Node.js `24.19.0`。

本地功能检查与正式发行验收已完成。产物、CI、安装、公开下载、签名及未覆盖项见[0.1.28 发行验收](0.1.28-verification.md)。
