# Rivloom 0.1.34

本版面向 Windows x64 重构桌面工作台、实时检查器与双栏设置界面；随包核心保持 OpenCode 1.18.33 与 Node.js 24.19.0，Linux x64 继续提供 0.1.30。 [正式下载](https://rivloom.com/download/)

## 工作台与交互

- 左侧改为 44px 活动栏与可折叠高密度会话抽屉（`Ctrl+B`），顶部收敛为单行面包屑并支持点击标题直接重命名，底部整合为无顶耳的双层统一输入区。
- 新建会话新增「任务驾驶舱」，展示本机与已配对设备就绪状态，支持点击切换首选/锁定路由或拖入文件直达目标设备；输入框支持 `/` 斜杠指令与个人提示词模板面板。

## 实时检查器与设置工作台

- 右侧检查器（`Ctrl+J`）整合「拓扑」「产物」「集群」三页：可查看可交互 SVG 多设备拓扑与按确认字节驱动的传输动效、点击节点筛选轨迹、集中查看多轮交付物与内联 Git 差异，以及管理执行队列与配对设备。
- 设置界面重构为分组双栏工作台，打开设置时桌面会话抽屉自动收起，模型、工作区、设备连接、诊断、知识库、待办与回收站统一导航与表单层次，并完整适配浅色、深色与窄窗口布局。
