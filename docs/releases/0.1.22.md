# Rivloom 0.1.22（未发布）

本版源码已准备，正式安装包和更新渠道尚未发布。当前可下载版本以[官网](https://rivloom.com/download/)为准。

## 聊天与工作区

- 侧栏、聊天区和队列栏使用更清晰的面板层次，调整消息气泡、过程面板、输入区与发送按钮；窄窗口保留紧凑布局。
- 侧栏底部导航收为图标入口，保留名称提示、键盘访问和待办数量。
- 统一按钮、消息、菜单、对话框和侧栏切换动效。减少动态效果偏好继续生效；不支持视图过渡的环境直接切换布局。
- 队列与设备栏在空闲时默认收起，有未结束执行项时自动展开；手动开合优先，收起时显示待执行数量。偏好仅保留在当前界面会话中。
- 消息次要操作在悬停或键盘聚焦时显示，最新结果和触屏环境继续保留可见入口。

## 菜单与版本显示

- 修复鼠标打开“更多”后“回收站”持续高亮的问题；保留键盘焦点、方向键选择和 Escape 返回。
- 左下角 Logo 旁显示实际桌面版本号，“关于”图标独立靠右。缩放侧栏时保持按钮大小和文字间距，较长标签可省略并通过提示查看。
- 浏览器预览显示预览标识；桌面版本仍从原生接口读取，不以写死的版本号替代读取失败。

## 范围与验证

本版保持现有附件、引用、排队发送和执行授权协议。固定核心仍为 **1.18.31-rivloom.9b07cf442a7e**，Node.js **24.19.0**。

界面已使用隔离合成数据检查鼠标、键盘、中英文及不同窗口/侧栏宽度。0.1.22 的正式构建、安装、更新和公开分发验收尚未执行；原生 WebView2、Linux WebKitGTK、真实模型与长会话性能仍需进一步验证。
