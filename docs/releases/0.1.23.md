# Rivloom 0.1.23

安装包与发行状态以官网及对应发行记录为准。

## 办公文件与模型连接

- 增加 PDF、Word（DOCX）、Excel（XLSX）本地预览，以及 CSV、TSV、TXT 和 Markdown 预览。支持 PDF 翻页与缩放、工作表切换和表格分页；所选文字或单元格可以引用到对话。
- 项目文件提供“在文件夹中打开”、系统默认应用打开、兼容格式使用 Chrome 或 Edge 打开、复制路径及另存为入口。小型 UTF-8 TXT、Markdown 文件支持编辑，并在未保存退出、覆盖或文件冲突时提示确认。
- 模型连接设置可从侧栏随时打开，首次使用也能进入同一配置界面。可保存多个连接的地址、凭据、模型与相关参数，便于在公网或不同内网环境之间切换；调整默认连接时保留已有草稿和运行中任务的模型选择。
- 文件解析与预览所需依赖随包提供，无需临时从公网下载。模型调用仍需能够访问用户配置的服务。

## 导航与交互

- 从待办列表进入会话时，侧栏同步定位到对应会话，并提供过渡动画及返回待办列表的入口。
- 整理侧栏、设置、消息工具栏、流程图和弹窗的布局，改善窄窗口、长文本、键盘焦点、加载、空列表及失败提示。
- 补齐模板、待发消息、流程步骤和文件编辑的未保存确认；确认窗口在桌面 WebView 中直接呈现。

## 支持范围

PDF 扫描件可查看，本版不提供 OCR。DOCX 预览不保证复现 Word 的所有复杂排版；XLSX 显示文件已保存的单元格结果，不执行公式、宏或外部链接。旧版 DOC、XLS 与 PPT 文件可交给外部应用打开。更多范围见[办公文件与模型连接](../OFFICE-WORKSPACE.md)。

真实内网模型的多步任务质量与复杂材料完整性，仍须按实际环境验证。固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 保持 `1.18.31`，Node.js 保持 `24.19.0`。
