# Rivloom 0.1.25

**2026-09-28：Windows / Linux x64 已正式发布，官网与签名更新已同步。** 详细产物、验收范围与限制见[本版验收](0.1.25-verification.md)。

## Node 活动与知识反馈

- 修正知识失败提示的清除竞态：同类操作再次失败后，旧提示发出的延迟清除请求不会误删新问题；累计失败次数继续保留。
- 修正终态任务迟到用量的处理：缺报仍在保留窗口内时，后续有效用量可以补齐统计，避免数据已完整却继续隐藏输入速率。过期执行不会因旧事件重放而重新出现。

## 模型连接

- 连接窗口与高级模型设置会在任务繁忙期间刷新状态，任务结束后恢复编辑，无需关闭页面重开。
- 调整刷新请求的时序，避免请求重叠及晚到的旧结果覆盖新的配置状态；本地校验失败后可以立即继续修改表单。
- 所选模型暂时不可用时保留该选择并提示原因。模型或可用性变化后需要重新确认连接测试，避免沿用旧同意向另一个模型发送请求。
- 保存连接、切换默认模型及随后刷新分别反映各自结果。已确认保存的配置或默认选择及时同步，后续失败仍显示错误。

## 办公文件预览

- 修正包含特殊 Unicode 字符时的查找高亮位置，避免高亮范围越界；Markdown 代码块中的匹配只计数一次。
- 搜索后切换编辑或关闭预览时，停止处理已移除元素的观察回调，避免残留回调触发异常。
- PDF 页面与完整 DOCX 排版预览不再显示无效的文字提取分页按钮；文本、表格及 Word 纯文本回退仍可分段查看。
- 预览读取失败后，另存为或外部打开等操作保留原来的错误与重试入口。
- 进入或退出编辑时清除旧选区，编辑期间禁用引用，并在发送引用前检查未保存内容，防止页面切换绕过编辑保护。

## 状态与支持范围

本版以修正已有功能为主。已通过相关逻辑回归、类型与双语检查，以及合成数据的浏览器交互验证。同提交 CI、隔离安装、公开完整下载、更新签名、Linux 隔离运行、官网同步与 R2 检查已完成；真实内网模型验收不在本次合成测试范围内。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin 保持 `1.18.31`，Node.js 保持 `24.19.0`。
