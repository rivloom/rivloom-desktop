# Rivloom Linux 0.1.29

Linux x64 无界面节点同步设备选择、消息续接、结果解析与停止收尾修复。任务中的“本机”以提交设备身份为准，规划位置与业务执行位置分别记录；上一轮安全结束后的新消息可继续处理。缺少空附件列表的完成结果可以解析，非法附件仍拒绝。

已确认取消的远端邀请可以正常收尾；旧投递失败不能覆盖后续取消消息的投递状态。无法确认停止的旧记录保持保护，升级不会强制解锁或重跑历史任务。

固定核心保持 `1.18.31-rivloom.9b07cf442a7e`，SDK/plugin `1.18.31`，Node.js `24.19.0`。Linux 继续手动停止节点、更换程序并保留数据目录，ARM64 暂不发布。安装方式见 [Linux 使用说明](../LINUX.md)，校验和不等同于数字签名。
