# Agent 基础工具

**状态：本地开发，尚未发布。** 本文描述当前源码新增的功能，不代表已发布的 0.1.18 安装包已经具备这些入口。Linux x64 0.1.18 的既有发行状态不受影响。

## 快速访问与输入

侧栏的「快速访问」或 `Ctrl / ⌘ + K` 可搜索操作、当前账号可见的会话和未发送草稿。方向键选择，Enter 打开，Esc 关闭。打开设置、队列和知识库时沿用原权限；命令面板本身不会发送消息、批准操作或启动任务。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / ⌘ + K | 快速访问 |
| Ctrl / ⌘ + Shift + N | 新会话 |
| Ctrl / ⌘ + Shift + F | 搜索历史会话 |
| Ctrl / ⌘ + Shift + L | 聚焦输入框 |
| Ctrl / ⌘ + F | 查找当前会话 |
| F3 / Shift + F3 | 当前会话下一个 / 上一个匹配片段 |

「键盘与输入」位于侧栏 Logo 上方，可选择 Enter 发送，或 Ctrl / ⌘ + Enter 发送、Enter 换行。界面按使用者当前设备显示快捷键：Windows/Linux 显示 Ctrl，macOS 显示 ⌘，不会同时列出两个系统的符号；远端执行设备不会影响本机键盘提示。Shift + Enter 始终换行。输入法候选、设备选择和其他弹窗处理自己的按键。浏览器或操作系统可能保留某些快捷键，对应按钮仍可使用。

草稿按账号与节点保存，切换会话不会清空未发送内容；侧栏显示草稿标记并支持仅查看有草稿的会话。「继续新会话草稿」可回到尚未建立会话的输入。附件上传失败的草稿也保留入口，上传是否可用仍由原附件恢复规则判断。

## 消息与模板

会话页采用紧凑的执行步骤概览，默认显示最多三条关键步骤，优先呈现失败、阻塞和正在执行的工作；可展开全部步骤并点击查看原始记录。节点来自已保存的执行记录，“本次用时”指最近一次尝试的记录区间，包含排队、执行和回执同步，不是全部重试的总耗时。缺少有效终态时间时不显示用时。

标题栏显示当前项目和已选模型；正文与输入框共用内容宽度，输入框随草稿自动增高。交付成果保留文件预览、保存和更多操作，长文件名在窄窗口中换行。

运行中会直接显示当前尝试最近同步的模型回复和工具动作，远端只显示已有执行摘要。待批准和待回答的内容默认可见；正常诊断可展开查看，失败、未知或未完整确认的诊断仍直接显示。完整工具和模型原文保留在步骤详情里。

- 用户要求可复用，回答可引用到输入框。原记录保持不变，插入后仍需手动发送。有正文草稿时选择追加或替换；超过当前输入上限、草稿已变化时不覆盖原内容。附件和执行设备选择保留。
- 提示词模板只保存到本机当前账号。可按名称或正文搜索、新建、编辑、删除；也可从当前草稿或示例开始。模板没有变量执行、自动发送或跨设备共享机制。
- 每个账号最多 100 个模板，名称 80 字符、正文 12000 字符。保存采用版本核对，其他窗口的改动不会被静默覆盖；发生冲突时保留当前编辑，并可另存新模板。
- 待执行消息可以修改正文，附件、消息标识和队列位置保留。保存不恢复暂停的队列。若消息已开始、已取消或被另一窗口修改，保存失败并保留编辑。当前正在执行的轮次不会被这项操作改写。

## 查找与导出

标题栏的查找按钮只搜索当前会话中可见的已同步需求、结果与执行摘要；不会改变侧栏的历史搜索条件。匹配计数按内容片段计算，同一段里的多个词不重复计数。查找历史轮次和折叠执行记录时会定位并展开相关内容。

导出按钮将当前会话的已同步可见记录保存为 Markdown 或 JSON。它是打开导出窗口时的快照，不是应用备份；没有恢复导入功能。附件只包含名称、类型和大小。不会额外导出工具完整输出、内部上下文、应用保存的模型配置和凭据。用户可见正文仍按原文导出，分享前应自行核对其中的信息。

远端会话在本机没有完整消息时，导出会明确标注只有需求和结果摘要。取消排队的消息和未发送草稿不在会话导出中。

## 用量与执行清单

本机 Task 的「用量与执行清单」展示官方引擎实际返回的会话累计 Token 和费用读数。重复轮询不会重复累加，缺失数据显示「未提供」，不估算上下文占比。费用沿用引擎原单位与估算，不能当作实际账单，也不能把 0 理解为免费。

执行清单来自本轮官方 `todowrite`，不是 Rivloom 根据回答推测的进度。读取失败不阻碍任务，停止或开始新一轮时不会把旧清单当作当前进度。工作流可在本机步骤详情里查看该步骤执行会话的读数；没有整个工作流或远端设备的合计统计。

## 项目改动审阅

工作区创建者可从标题栏查看当前会话对应的本机已登记项目，或新会话选择的项目。面板分别展示未暂存和已暂存的 Git 差异，可筛选文件路径、手动刷新。这里包含用户和其他工具的修改，不能视为全部由某次 Agent 任务产生。

此入口只读，不暂存、提交、推送或恢复文件，不运行仓库配置的 diff、textconv、filter 或 fsmonitor 命令。敏感名称、二进制、非 UTF-8、链接、特殊文件和超限内容不在面板中展开；大列表最多展示 500 个文件，单份差异最多 256 KiB / 5000 行。已知凭据形态会脱敏，但这不构成通用秘密检测器。

Git 的读取范围固定为已登记的物理项目目录，仓库的 `core.worktree` 不能将读取重定向到另一工作区。该功能运行于用户本机权限下，不是对抗同一操作系统用户主动并发替换文件、父目录或 Git 元数据的安全沙箱。

## 本地验收

`npm run preview:agent-foundations` 构建并启动只监听回环地址的预览，终端会给出 URL。预览使用合成会话、隔离 SQLite 和临时 Git 项目；模板和项目差异通过实际服务实现，排队编辑复用实际工作流服务。它不调用模型、不派发任务，也不读取安装版的数据。Ctrl+C 结束预览；真实账号、配对设备与系统启动服务应另行验收。
