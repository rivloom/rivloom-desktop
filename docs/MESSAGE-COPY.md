# 消息复制与正文选择

更新：2026-09-10，0.1.11。

用户消息仅显示原始正文，气泡的颜色和位置继续区分消息来源；屏幕阅读器保留用户/来件来源名称。鼠标移到消息或执行结果时出现 13 像素复制图标，26 像素按钮不增加标题行或改变正文尺寸，移开后隐藏。复制成功短暂显示勾选反馈，失败显示可重试的说明。普通消息、补充要求、工作流需求、最终结果、步骤结果及展开的工具输出使用相同图标行为。关于窗口的版本信息复制保留文字按钮。

键盘 Tab 聚焦时显示复制按钮，Enter/Space 可操作。无悬停或粗指针设备保留可见的小图标与 36 像素点击区域。正文允许鼠标拖选和系统复制，选中底色使用 #bfd5ff；应用仍只在拖动侧栏尺寸时临时禁用选择。全文复制以实际展示文本为准，保留空行、换行及缩进，不包含作者、图标或内部执行封装。

实现涉及 src/copy-button.tsx、src/conversation-workspace.tsx、src/workflow-view.tsx 及对应样式，未修改任务内容或存储结构。
