# 办公文件与模型连接

2026-09-27：本页功能纳入 0.1.23 发行准备。当前已完成发行仍为 0.1.22；0.1.23 的安装包与发行状态以[官网](https://rivloom.com/download/)及[本版说明](releases/0.1.23.md)为准。

## 模型连接

工作区创建者可从左下角「模型连接」或模型菜单的「管理连接」随时打开配置窗口。首次无可用模型时提供同一套引导；「稍后配置」状态保存在本机数据库，重启不会再次弹出。

每个连接保存名称、完整 API 地址、模型 ID、认证方式，以及高级设置中的接口协议、上下文容量和最大输出。可以保存公司内网、家庭和其他办公环境。项目、历史会话和设备配对不受影响；已有厂商账号和 OAuth 接入从「厂商账号与更多设置」继续管理。

留空已保存连接的密钥会保留原密钥，勾选免认证会删除旧凭据。保存不发送模型推理请求；连接测试需明确同意，向所选已保存模型发送一次最小请求。

「使用此连接」和「保存并使用」调整新任务默认模型，既有任务和未发送草稿保留各自选择。执行中修改连接受原有忙碌锁保护。保存的默认模型暂不可用时保留选择并提示检查，不自动采用另一服务；主动删除默认连接后需重新选择。

## 预览与编辑

点击已备妥附件、任务材料或成果的文件名打开统一预览，流程中的文件共用该入口。远端文件需先取回。「项目文件」可浏览已登记的本机项目、进入目录和搜索文件名。

| 格式 | 支持范围 |
| --- | --- |
| PDF | 本机渲染、翻页、缩放、文字选择和当前页查找；扫描件可看页面，未提供 OCR |
| DOCX | 正文、标题、列表、表格和受限嵌入图片；阅读版式不保证与 Word 完全一致 |
| XLSX | 工作表、分页表格、单元格和当前批次查找；显示已保存公式结果，不运行公式、宏或外部链接 |
| CSV / TSV | 引号、分隔符和换行解析，按行分页 |
| TXT / Markdown | 文字、排版/源码预览，以及完整小文件编辑 |
| 图片 / 音视频 | 图片缩放和浏览器支持的媒体播放 |
| DOC / XLS / PPT 等 | 暂无内置预览，可另存或使用系统应用 |

工具栏提供「在文件夹中打开」、默认应用、兼容格式的已安装 Chrome / Edge、系统应用选择器、复制路径和另存为。选择其他应用和指定浏览器本次实现于 Windows。超出预览限制的项目文件仍可使用原生打开入口。

选中文字或单元格后，「引用到聊天」创建独立引用卡片并附文件名及页码/工作表信息；已有引用会先询问替换。

只编辑完整读取的 UTF-8 TXT / Markdown，最大 256 KiB。项目文件保存前核对 SHA-256，发生外部修改时保留草稿并拒绝覆盖；正常保存使用同目录临时文件和原子替换。历史附件和成果编辑后选择保存新副本（浏览器模式下载），原 ID、哈希和任务快照不变。目标文件已存在时拒绝覆盖；关闭未保存编辑会提示。

## 离线与读取边界

PDF.js、Mammoth、ExcelJS 和 HTML 清理器随运行包分发，PDF 工作线程、字体、CMap、WASM 从本机加载，不依赖 CDN 或公网 Office 查看服务。模型处理仍需连接用户配置的服务，更新检查沿用原机制。

解析单文件最大 32 MiB，最多两个 worker，单次 25 秒，JavaScript 老生代堆上限 384 MiB（不是进程总内存上限）。ZIP 先检查条目、加密标志和声明的解压大小。表格每批最多 100 行、100 列，单元格最多 2000 字符；超限明确提示。项目列表最多 500 项，搜索最多扫描 5000 项、深入六层。拒绝越界、链接、硬链接、已知敏感文件名及内部目录；这些本机访问约束不是对抗同一系统用户并发替换目录的隔离沙箱。

`rivloom_document_read` 通过现有上下文桥接，仅允许活动任务读取授权项目和已物化输入材料。参数为相对 `path`、PDF `page`（从 1 起）、`sheet`（从 0 起）、`offset` 及可选 `expectedRevision`。返回来源、修订、截断与警告，最大 32 KiB 序列化 UTF-8。普通文档按 `nextOffset` 继续；宽表先按 `nextTextOffset` → `textOffset` 读完同一批行，再按 `nextOffset` → `offset` 继续并清零 `textOffset`。调用者应逐页、逐表核对，不将片段当成完整材料。

本轮通过合成文件的解析/API/保存冲突回归、拒绝公网资源的 Edge 与真实 WebView2 预览，以及固定引擎和回环合成模型的多步读取、越界拒绝后恢复、写报告和重启保持配置验收。真实内网模型可靠性、长材料完整性及复杂版式仍需实际模型和业务材料验收。
